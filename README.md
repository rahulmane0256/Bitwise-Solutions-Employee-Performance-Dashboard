# Bitwise Solutions Employee Performance Dashboard

## Project Overview
This project is an interactive Power BI dashboard created to analyze employee performance, salary trends, billable hours, project allocation, and workforce distribution using a sample dataset.

## Tools Used
- Microsoft Power BI
- Microsoft Excel
- DAX

## Dashboard KPIs
- Total Employees
- Average Salary
- Highest Salary
- Total Billable Hours
- Average Performance

## Features
- Interactive KPI Cards
- Salary Analysis by Department
- Billable Hours by Client
- Employee Distribution by Location
- Project Distribution
- Employee Joining Trend
- Interactive Slicers
